# Franka Reflex: Real-Time Kinematic Control using Artifical Potential Fields
Author: Kyuwon Weon 

Goal: A ROS 2 package that implements Artificial Potential Fields to control a Franka Emika Panda robot. The controller navigates the robot arm toward a dynamic target while avoiding obstacles in a MuJoCo physics simulation.


Following is the demo video. The red circle is the obstacle, and the green circle is the target that can be interactively moved around.
